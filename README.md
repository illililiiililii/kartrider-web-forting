# KartRider Web · P5136 로컬 포트

제공된 `C:\Users\user\Downloads\kart web` 파일에서 추출한 에셋으로 달리는 브라우저 프로토타입입니다. 원본 실행 파일 자체를 웹에서 실행하거나 원본 온라인 서버에 접속하지는 않습니다.

## 실행

Node.js가 설치된 PC에서 `Start.cmd`를 더블클릭하거나 이 폴더에서 `npm start`를 실행합니다. 주소는 http://127.0.0.1:8316/ 입니다. `node server.mjs --port 8317`로 포트를 바꿀 수 있습니다. 다른 기기와 같은 LAN에서 달리려면 `node server.mjs --lan`을 실행하고 호스트 PC의 LAN IP 주소로 접속합니다. 서버 의존성 `ws`가 없을 때는 이 폴더에서 `npm install`을 실행합니다.

## 구현

- 원본 P5136 트랙 5종: 빌리지 고가의 질주, 빌리지 시계탑, 포레스트 통나무, 사막 피라미드 탐험, 아이스 상어의 무덤. 트랙 메시·텍스처·충돌 메시·코스 게이트·썸네일·BGM을 사용합니다.
- V1 카트 8종 선택: 스펙터, 백기사, 스톰, 코튼, 세이버, 산군, 타이탄, 연습카트. 원본 모델·스킨과 공개된 P5136 설정 파일의 일부 수치를 사용합니다.
- 다오, 배찌, 디지니, 마리드 선택. 원본 얼굴 텍스처를 단순한 웹용 3D 운전자 몸체에 입혔습니다.
- 타임어택, 체크포인트와 랩 판정, 로컬 개인 최고 기록, 부스터 충전·사용, 미니맵.
- 동일 서버 접속자 최대 8명의 방 코드 멀티플레이: 방장 출발, 같은 트랙, 다른 라이더 위치 동기화, 완주 기록 표시. 로컬/LAN 서버이며 원본 계정·매치메이킹과 연동되지 않습니다.

## 주행 물리

기존 단순한 방향 보간 모델을 제거했습니다. `driving.js`는 공개된 구형 카트라이더 데모 물리 구현의 조향 감쇠, 앞·뒤 슬립각, 타이어 횡력, 드리프트 진입·지속·이탈 상태를 참고합니다. P5136 V1 `BodyParam`의 일부 값을 카트별 상대적인 튜닝에 적용합니다. 120Hz 고정 스텝으로 주행하고 원본 트랙 충돌 메시와 바닥 높이를 사용합니다. 드리프트 진입 때 뒤쪽 접지력이 무너지고, 차체가 회전하면서 진행 방향과 차체 방향이 어긋나며, 키를 놓으면 접지력을 회복합니다.

**원본 P5136 클라이언트 물리와 동일하다는 뜻은 아닙니다.** 버전이 다른 데모의 방정식을 웹 환경에 맞춰 재구성한 것이며, 바퀴별 서스펜션·정확한 충돌 형상·원본 튜닝 상수·프레임 단위 비교는 아직 없습니다. 원작의 세부 드리프트 테크닉과 계기판 속도 수치를 완전히 재현하지 못합니다.

## 파일과 검증

- `game.js`: 씬·입력·HUD·멀티플레이 클라이언트
- `driving.js`: 주행 물리
- `physics.js`: 게이트·랩 판정
- `server.mjs`: 로컬 정적 서버와 WebSocket 방 서버
- `assets/catalog.json`: 선택 가능한 트랙·카트·캐릭터
- `tests/`: `npm test`로 실행하는 데이터·물리 검증

`REA-installation.json`에는 공식 npm 패키지 `rea-agents@6.5.0`의 Codex 등록 결과가 있습니다. 네이티브 분석 엔진을 이용한 P5136 원본 클라이언트 물리 함수의 디컴파일은 수행되지 않았습니다.
