# 로컬 웹 포팅 · 실험판

원본 P5136 클라이언트와 서버에 접속하는 게임이 아니라, 사용자가 제공한 P5136 에셋과 공개 자료를 이용해 브라우저에서 재구성 중인 프로젝트입니다. 주행은 계속 비교·보정 중입니다.

# P5136 Web · P5136 로컬 포트

## 실행

Node.js가 설치된 PC에서 `Start.cmd`를 더블클릭하거나 이 폴더에서 `npm start`를 실행합니다. 주소는 http://127.0.0.1:8316/ 입니다. `node server.mjs --port 8317`로 포트를 바꿀 수 있습니다. 다른 기기와 같은 LAN에서 달리려면 `node server.mjs --lan`을 실행하고 호스트 PC의 LAN IP 주소로 접속합니다. 서버 의존성 `ws`가 없을 때는 이 폴더에서 `npm install`을 실행합니다.

## 구현

- 원본 P5136 트랙 5종: 빌리지 고가의 질주, 빌리지 시계탑, 포레스트 통나무, 사막 피라미드 탐험, 아이스 상어의 무덤. 트랙 메시·텍스처·충돌 메시·코스 게이트·썸네일·BGM을 사용합니다.
- V1 카트 8종 선택: 스펙터, 백기사, 스톰, 코튼, 세이버, 산군, 타이탄, 연습카트. 원본 모델·스킨과 공개된 P5136 설정 파일의 일부 수치를 사용합니다.
- 다오, 배찌, 디지니, 마리드 선택. 원본 얼굴 텍스처를 단순한 웹용 3D 운전자 몸체에 입혔습니다.
- 타임어택, 체크포인트와 랩 판정, 로컬 개인 최고 기록, 부스터 충전·사용, 미니맵.
- 동일 서버 접속자 최대 8명의 방 코드 멀티플레이: 방장 출발, 같은 트랙, 다른 라이더 위치 동기화, 완주 기록 표시. 로컬/LAN 서버이며 원본 계정·매치메이킹과 연동되지 않습니다.

## 주행 물리

`driving.js`는 브라우저 프레임에서 5 ms씩 입력을 처리하고, 각 입력 틱을 P5136에서 확인한 최대 2 ms 물리 단계로 나눕니다. 바퀴 4개의 트랙 접촉과 서스펜션, 전후 구동·제동·후진, 조향 감쇠, 앞뒤 타이어 슬립/횡력, 드리프트 상태와 yaw/roll 토크, 공중 중력, 선형·제곱 항력, 쿼터니언 자세 적분, 벽/바닥 충돌 응답을 계산합니다. 각 바퀴의 지면은 제공 트랙 충돌 메시에서 레이캐스트합니다. 선택한 V1 카트에는 한국 지역 P5136 파라미터 파일에서 얻은 BodyParam 수치를 연결합니다. 스펙터 V1 예시는 출발 가속 계수 1.8, 출발 부스터 1.4초, 기본 2.9초에 XML 보정값을 더한 일반 부스터 시간 2.965초입니다.

주행식과 상태 전이 순서는 `KartriderDemoPhysics`의 2004 데모 실행 파일에서 복원한 알고리즘을 웹용 3D 강체 시뮬레이션으로 옮긴 것입니다. P5136의 S7 속도 프리셋과 카트별 BodyParam 합산식은 공개 P5136 서버 코드와 대조했습니다. **실행 중인 P5136 클라이언트의 메모리에서 풀린 물리 함수를 확보하고 Ghidra로 디컴파일해 2 ms 틱, 서스펜션 식, 호출 순서와 일부 필드를 확인했습니다.** 아직 종력·횡력·드리프트·게이지의 전체 수식과 원본 대비 주행 시계열 오차는 복원하지 못했습니다. 따라서 현재 웹 물리는 원본과 동일하지 않습니다. 확인된 범위, 분석 산출물 및 부족한 증거는 [reader.md](reader.md)에 기록했습니다. `npm test`는 웹 코드의 내부 일관성을 확인하며 원본 동등성 시험은 아닙니다.

## 파일과 검증

- `game.js`: 씬·입력·HUD·멀티플레이 클라이언트
- `driving.js`: 주행 물리
- `physics.js`: 게이트·랩 판정
- `server.mjs`: 로컬 정적 서버와 WebSocket 방 서버
- `assets/catalog.json`: 선택 가능한 트랙·카트·캐릭터
- `tests/`: `npm test`로 실행하는 데이터·물리 검증

`REA-installation.json`에는 공식 npm 패키지 `rea-agents@6.5.0`의 Codex 등록 결과가 있습니다. P5136 디스크 실행 파일은 보호되어 있었으나, 실행 중 메모리의 주행 코드를 별도로 복원해 일부 함수를 분석했습니다. 원본 RHO/RHO5 팩에서 복호화한 로비 BML과 버튼 리소스도 적용했습니다.
